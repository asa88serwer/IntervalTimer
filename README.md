# IntervalTime

Android-приложение: секундомер + таймер обратного отсчёта с разбиением на интервалы (1–10),
голосовыми оповещениями и работой в фоне.

## Что уже реализовано (базовая часть)

- Единый главный экран: бирюзово-чёрный градиент (преимущественно бирюзовый, чёрный только
  по самым краям), по центру круглая кнопка **Старт**, вокруг неё — кольцо из дуг-сегментов
  (по одной на период), которое медленно вращается и «пульсирует» при изменении числа интервалов
- Режим **«Обратный отсчёт»** — количество раундов задаётся кнопками 1–10; переключатель
  «Одинаковые / Разные» — либо единая длительность работы/отдыха на все раунды, либо у каждого
  раунда своя длительность (список степперов по раундам)
- Режим **«Секундомер»** — открывает экран с **двумя независимыми секундомерами**, которые можно
  запускать, ставить на паузу, фиксировать круги и останавливать по отдельности, не мешая друг
  другу (каждый — свой экземпляр движка, тикают по-настоящему параллельно). У каждого секундомера
  свой **динамический градиент**-фон (плавно и медленно перетекающие оттенки, свой цвет у каждого —
  визуально различимы). Время — с сотыми долями секунды, результат (время + круги) автосохраняется
  при «Стоп» — история открывается через иконку в шапке главного экрана
- Голосовые оповещения (TextToSpeech): старт, конец периода/тренировки, отсчёт последних секунд,
  минутные отметки в режиме секундомера; в Настройках — скорость речи и язык (RU/EN)
- Работа в фоне: foreground-сервис + постоянное уведомление с кнопками Пауза/Далее/Стоп,
  таймер продолжает отсчёт и озвучку при заблокированном экране; пауза корректно замораживает
  время (без «убегания» вперёд после возобновления)
- Цветовая индикация фазы — фон экрана таймера меняется (работа/отдых/нейтрально)
- Собственные шаблоны (название + настройки раундов) сохраняются на устройстве и открываются
  через кнопку со списком в шапке главного экрана
- Всё управление — на одном экране, без переходов на отдельные экраны редактирования

## Что добавим следующим шагом

Виджет на главный экран, Wear OS companion, синхронизация пульса (Health Connect / BLE),
обмен шаблонами по ссылке/QR — сознательно отложено, чтобы сначала собрать и проверить
стабильно работающую основу.

## Как собрать и запустить

1. **Установите Android Studio** (бесплатно): https://developer.android.com/studio
   Скачивает и настраивает JDK и Gradle сама — отдельно ставить ничего не нужно.
2. Откройте Android Studio → **Open** → выберите папку `IntervalTimer` (эту).
3. При первом открытии Android Studio предложит создать Gradle wrapper —
   согласитесь («Create Gradle Wrapper» / OK). Дождитесь синхронизации проекта
   (полоса прогресса внизу окна) — займёт несколько минут при первом запуске,
   скачаются зависимости.
4. Подключите телефон по USB:
   - На телефоне: **Настройки → О телефоне** → 7 раз нажать «Номер сборки» (включит «Для разработчиков»)
   - **Настройки → Для разработчиков** → включить «Отладка по USB»
   - Подключите кабелем, на телефоне подтвердите запрос отладки при подключении
   - Либо запустите виртуальное устройство (эмулятор) через Device Manager в Android Studio
5. Нажмите зелёный **Run ▶** в Android Studio — приложение соберётся и установится на телефон/эмулятор.

Разрешение на уведомления система запросит при первом запуске — без него не будет видно
уведомление таймера (сам таймер и голос при этом всё равно работают).

## Структура проекта

```
app/src/main/java/ru/anikin/intervaltime/
  data/            модели (Period, Workout, StopwatchResult), IntervalBuilder,
                   хранилище шаблонов и хранилище результатов секундомера
  timer/           TimerEngine (класс движка), TimerEngines (3 экземпляра: обратный отсчёт
                   и два независимых секундомера), TimerService (фоновая работа)
  tts/             VoiceAnnouncer (голосовые оповещения)
  notification/    уведомление таймера с кнопками управления
  ui/
    components/    PeriodRing — кольцо из дуг вокруг кнопки Старт
    screens/       главный экран, экран обратного отсчёта, экран двух секундомеров, настройки
```
